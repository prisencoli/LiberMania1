Checklist Dettagliata Progetto LiberMania (Web First)

Fase 0: Setup e Configurazione Globale

Ambiente Sviluppo Locale:

Node.js e npm/yarn installati e funzionanti.

PostgreSQL installato, server in esecuzione.

Database libermania_db creato con utente dedicato (libermania_user).

pgAdmin o simile per accesso al DB.

Git inizializzato per backend e frontend.

VS Code (o altro editor) configurato.

Progetto Backend (NestJS):

Progetto creato (nest new libermania-backend).

Dipendenze principali installate (@nestjs/config, @nestjs/typeorm, typeorm, pg, class-validator, class-transformer, bcrypt).

File .env creato con variabili DB, JWT, ecc.

ConfigModule configurato in app.module.ts (isGlobal: true).

TypeOrmModule configurato in app.module.ts (connessione DB, caricamento entità - usare elenco esplicito).

ValidationPipe globale configurato in main.ts.

CORS configurato in main.ts.

Body Parser per rawBody configurato in main.ts (per webhook).

Progetto Frontend (Next.js):

Progetto creato (create-next-app con TypeScript, Tailwind, App Router).

Variabili d'ambiente (.env.local) create (NEXT_PUBLIC_API_URL, chiavi pubblicabili Stripe/PayPal, GA ID, ecc.).

Configurazione Tailwind (tailwind.config.js) con font e colori custom.

globals.css aggiornato.

Layout Radice (src/app/layout.tsx) con font, AuthProvider, Header, Footer, Toaster, CookieConsent.

Servizi Esterni (Account Creati):

Google Cloud Platform (per Google Books API, Google Places API).

Cloudinary (per storage immagini).

Stripe (account, chiavi API test/live, webhook endpoint creato).

PayPal (account developer sandbox/live, app creata, credenziali, webhook ID).

Firebase (progetto creato, service account key generata per FCM).

(Opzionale) Servizio Email Transazionale (SendGrid/Mailgun/etc., API key).

(Opzionale) Google Analytics (Property ID).
